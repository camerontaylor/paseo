## Regression found and fixed in assembly

**Symptom.** After the clean merge, `npx vitest run src/server/agent/agent-manager.test.ts` →
209/210: *“does not replace a newer foreground turn after unavailable steer fallback is admitted”*
fails deterministically (single-test rerun fails too; the identical run on
`tmad-port/baseline-assembly` passes, same clone, same dist:
`logs/p2-test-agent-manager{,-baseline-run,-rerun}.log`). The steer path's next foreground start was
rejected with "Agent … already has an active run".

**Mechanism (trace-verified, `logs/p2-test-agent-manager-trace.log`, with a temporary trace-level
test logger, reverted).** TM-01's port made `collectArtifactsForTurn` awaited inside
`dispatchSessionEvent`, between `handleStreamEvent` (run settled) and `runs.notifyWaiters`
(consumers released). The steer admission's barrier replay (a stray `turn_started`) slipped into
that new async window and was processed before the test could start turn B; its handler re-marked
the agent `running` and left a ghost tracked run (`hasTrackedRun=True`,
`activeForegroundTurnId=None`) that rejected B's start. On the baseline (no await), the same replay
lands only after B has already replaced the tracked run — harmless.

**Source fidelity.** The reconciled source never awaits this call — `51fb7693d` line 4012:
`void this.collectArtifactsForTurn(agent);` with the comment: *"Artifact collection walks the
working directory. Never hold the turn's waiters on it: upstream settles and notifies at the
terminal event, and a steer or replace admitted during the walk must see the run already settled."*
TM-01's port changed `void` → `await` and dropped the comment (undisclosed in TM-01's seam table
and ledger, which list the hook's placement but not this delta). The fix restores source semantics
verbatim, comment included.

**Fix.** `d17896891` (one hunk, `packages/server/src/server/agent/agent-manager.ts`): `await` →
`void` + source comment. Green after fix: agent-manager 210/210, steer test rerun pass, companion 12,
collector 3, backfill 5, authorization 7, all app/protocol suites re-run green (§Results).
Build/typecheck/lint re-run green.
