## Native evidence still required

Run on an iOS simulator and an Android device/emulator before promotion. Per state:

1. **Reachability.** Open a chat tab -> open the tab menu (mobile kebab) -> confirm
   "Find in chat" appears with a search icon, is localized, and is tappable.
2. **Open + focus.** Confirm the Find widget opens with the text field focused, and
   that tapping the same menu item for a background agent focuses that agent's tab and
   opens Find there.
3. **Loaded match.** Query a term present in the on-screen history. Expect the
   occurrence counter to read `1 of N`, the match to advance with next/previous, and the
   selected row to be tinted.
4. **Historical match (the key case).** Query a term that only exists far above the
   loaded window. Expect: the list scrolls to the row, the row mounts, the counter shows
   the whole-chat position, and the tinted row is visible. Verify `onScrollToIndexFailed`
   retry does not visibly jump-then-snap on a long chat with variable row heights.
5. **Live head match.** Query a term in the most recent assistant turn (rendered in the
   inverted list header). Expect scroll-to-offset 0, not a wrong index.
6. **Wrap-around and zero matches.** Next/previous past the ends should wrap; a
   no-match query should show "No matches" and not leave a stale tint.
7. **Cleanup.** Background the panel (switch tabs / open the Stream-free panel switcher)
   and return: Find must be closed, no tint remaining, and reopening must show an empty
   query. Unmount the agent tab mid-search and confirm no setState-after-unmount warning.
8. **Older host.** Connect to a daemon without `agentHistorySearch` and confirm the
   widget stays reachable and shows the "Update the host to use Find" status rather than
   hiding or erroring.
9. **Keyboard.** Confirm the on-screen keyboard does not cover the widget and that
   dismiss/scroll still behaves with the widget open.
10. **Orientation / rotation** and both locales with non-Latin scripts (ko, ja, zh-CN) to
    check the overlay's `left`/`right` insets and status text truncation.
