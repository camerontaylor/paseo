## s0 — environment incident: shared `node_modules` symlinks (2026-10-14)

Recorded because it is a hazard for every later neptune worker, not only B9.

This worktree was provisioned with `packages/*/node_modules` as **symlinks into the shared main checkout** `/Volumes/offload/neptune/repos/paseo` (11 links, created 14 Oct 23:47). The worktree's own root `node_modules` was a real directory.

`ONNXRUNTIME_NODE_INSTALL=skip npm ci` failed in 1 s:

```
npm error code ENOTDIR
npm error syscall mkdir
npm error path /Users/ctaylor/.paseo/worktrees/1ns0r9d9/b9-diff-stat/packages/app/node_modules/@xterm
```

npm's debug log (`~/.cache/npm/_logs/2026-10-14T12_51_04_469Z-debug-0.log`) shows the failure is in `reify:createSparse` (`reify moves {}` then the stack at `arborist/lib/arborist/reify.js:624`), i.e. before any package unpack. Cause: `_createSparseTree` walks up from each leaf path, `lstat`s each component, and treats a non-directory component (a **dangling symlink**) as something to retire; the concurrent `Promise.allSettled` mkdirs race through the symlink and one of them returns ENOTDIR. The symlink chain made npm write into the shared main checkout.

Damage assessment on the main checkout (all evidence collected before any repair):

- Root `node_modules` untouched: 1412 entries, mtime 2 Oct 12:31, not a symlink.
- `packages/*/node_modules` in main: 4 pre-existed (client 29 Sep, highlight 7 Sep, plugin/protocol 11 Oct) and were **already empty**; 7 (app, cli, desktop, expo-two-way-audio, relay, server, website) had mtime 14 Oct 23:51, i.e. created by this failed run. Every one of the 11 contained **zero files at any depth** (`find -type f | wc -l` = 0).
- `git status` in main unchanged (`?? plans/` only, pre-existing).

Repair: the 7 created empty placeholder directories were removed (verified 0 files each first), restoring main to exactly its prior state. The 11 symlinks in this worktree were then removed so that installs create real per-workspace directories inside the worktree and can never write into the shared checkout again. `npm ci` was re-run in the worktree.

Conclusion: no package, tracked file, branch or frozen ref was affected; the only real cost was one wasted install and the diagnosis. Every later neptune worker with symlinked `packages/*/node_modules` will hit the same ENOTDIR.
